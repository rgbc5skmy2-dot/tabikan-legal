# tabikan-legal

Tabikan の利用規約・プライバシーポリシーの公開ページ（GitHub Pages）。lumap-legal と同じ作り。
App Store Connect に登録する URL（公開後）:

- サポート: https://rgbc5skmy2-dot.github.io/tabikan-legal/
- プライバシーポリシー: https://rgbc5skmy2-dot.github.io/tabikan-legal/privacy.html
- 利用規約: https://rgbc5skmy2-dot.github.io/tabikan-legal/terms.html

アプリの `Tabikan/src/appInfo.ts`（`LEGAL_SITE`・`TERMS_URL`・`PRIVACY_URL`）と URL をそろえること。

AdMob の `app-ads.txt` はドメインのルート（`https://rgbc5skmy2-dot.github.io/app-ads.txt`）に置く。
Lumap と同じ AdMob アカウントなら、すでに置いてあるものがそのまま使える。
